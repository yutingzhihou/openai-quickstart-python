# Codex practice guide

This fork is a safe place to practice a complete Codex and GitHub workflow.

## Suggested exercises

1. Ask Codex to explain the repository structure.
2. Ask Codex to find outdated API examples.
3. Create a branch for one small change.
4. Run or add tests before committing.
5. Open a pull request and ask Codex to review the diff.

## Pull request checklist

- Keep the change focused.
- Never commit API keys or the `.env` file.
- Explain what changed and why.
- Include verification steps.
- Review the generated diff before merging.
